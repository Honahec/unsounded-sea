# 3D 战斗验证记录

2026-10-16，macOS / Unity 6000.6.5f1 / Unity CLI 1.0.0-beta.13 / Pipeline 0.8.0-exp.1。当前范围是 `OceanBattle.unity` 的「雾海来客」与 `SeaBossBattle.unity` 的「沉钟海域」；旧 HUD 的逐轮记录保留在 Git 历史，不重复维护。

## 规则与配置

EditMode：**45 通过 / 0 失败 / 0 跳过**。保留原有 30 项规则回归，增加 6 项场景配置与双敌遭遇测试：

- 场景、相机、角色和出生点引用完整。
- 重开拥有独立目标进度、工具次数与调查状态。
- 四段封线在两个敌人仍存活时获胜，同回合不能重复封线。
- 忽略目标最终失败，终局拒绝后续命令。
- 指向一个敌人的伤害不影响另一个。
- 规则模块每次创建独立目标，不共享可变状态。

另有 6 项海面 Boss 检查：独立海面锚点与体量、带旋转缩放的局部碰撞边界、错误挂在船体下时拒绝配置、禁止任务/卡牌推进生存进度、32 个种子下不防御均失败、同组种子下按公开征兆防御且不使用工具均获胜。

3 项水体单测覆盖暂停时钟、减少动效连续相位、重绑/解绑资源释放、源材质与反射层保留、船体采样与材质波相位/暂停时钟一致；实际停用和销毁回调另由 Play 模式流程验证。

原回归覆盖确定性回放、无效命令零扣费、抽弃牌守恒、调查不重掷意图、资源防护、消耗牌、存档和地图约束。执行命令见 [框架指南](FRAMEWORK.md)。

使用 `wait_for(Time.frameCount changed)` 确认玩家循环推进。通过 UI Toolkit 的 NavigationSubmit / PointerDown 事件触发真实按钮和模型选择回调；这不是对所有鼠标、触屏或手柄设备的验证。可复现辅助入口位于 `Tools/OceanBattleQA.cs`、`Tools/SeaBossQA.cs` 和 `Tools/UberWaterQA.cs`。

| 验证 | 结果 |
| --- | --- |
| 双目标选择与出牌 | 选中 Echo 后使用撕毁符纸：999 → 995，祷告者仍 30 |
