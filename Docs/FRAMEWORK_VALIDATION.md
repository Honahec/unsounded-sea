## 局外航海

以下完整航程实机记录来自合并 `e9d1a16` 后的航海版本；随后同步 `f34a850` 时，战斗脚本、效果、Scenario 和两个主线战斗场景均保留对方实现，不以本节代替下文的新 Boss 验收。

- 最新 `main`（`f34a850`）合并后，航海专项 EditMode 回归 **21 通过 / 0 失败**；标题保留主线 Boss 快捷入口。没有重新制作或改写对方战斗效果。

- 实际标题按钮进入航图，起步仅 3 个已知地点；望远镜后为 6 个，余次 2 → 1；完整地图 JSON 不变，文件读档保留选择、知识和次数。当前 UI 与测试航图文本未发现缺失字形。
- 种子 18 实际完成六地点、五段航行、四场主线既有遭遇，共 50 次战斗按钮操作；航时 25 小时，整张生成图未变化。航海侧只传入节点种子、记录公开胜负，保留对方的终局重开和返回标题控件。
- 航行中实测相机移动约 1.218 m、海景根移动约 0.487 m；抵达恢复原姿态且只计段一次。减少动效检查中相机与海景均未位移。

本地报告与截图位于被忽略的 `Logs/VoyageVerification/`；不是团队唯一交付。规则与复现入口见 [框架指南](FRAMEWORK.md#航海选路局外)。航海仍使用灰盒，没有制作新的战斗变体、航程经济或正式船景；未做独立 Player 或性能验收。

## 规则与配置

同步 main UI 重设计（`15c9a81`）及海面光照修正后，完整 EditMode：**66 通过 / 0 失败 / 0 跳过**（45 项战斗/水体 + 21 项航程）。保留原有 30 项规则回归，增加 6 项场景配置与双敌遭遇测试：

- 场景、相机、角色和出生点引用完整。
- 重开拥有独立目标进度、工具次数与调查状态。
- 四段封线在两个敌人仍存活时获胜，同回合不能重复封线。
- 忽略目标最终失败，终局拒绝后续命令。
- 指向一个敌人的伤害不影响另一个。
- 规则模块每次创建独立目标，不共享可变状态。

另有 6 项海面 Boss 检查：独立海面锚点与体量、带旋转缩放的局部碰撞边界、错误挂在船体下时拒绝配置、禁止任务/卡牌推进生存进度、32 个种子下不防御均失败、同组种子下按公开征兆防御且不使用工具均获胜。

3 项水体单测覆盖暂停时钟、减少动效连续相位、重绑/解绑资源释放、源材质与反射层保留、船体采样与材质波相位/暂停时钟一致；实际停用和销毁回调另由 Play 模式流程验证。

原回归覆盖确定性回放、无效命令零扣费、抽弃牌守恒、调查不重掷意图、资源防护、消耗牌、存档和地图约束。执行命令见 [框架指南](FRAMEWORK.md)。
