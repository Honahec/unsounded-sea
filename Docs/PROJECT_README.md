## 一、项目简介

《未测之海》是一款克苏鲁调查题材的回合制卡牌构筑 Roguelike，使用 Unity 6（URP）开发，采用固定镜头 3D 海上场景与 2D 卡牌界面。

玩家扮演调查员，乘调查船驶入地图与现实逐渐失效的海域。敌人的行动会提前锁定，玩家能看到征兆，却不天然知道完整意图；需要借助提灯、听筒等调查工具、档案与禁忌知识获取局部信息，再结合手牌与资源应对。胜利往往不是“打空血条”，而是在不完整认知下完成封线、存活撤离、解谜封印或击退等局部目标。

设计关键词：

- **有限认知**：每个未知都有征兆或通用防护路线；调查只回答限定问题，不重新随机敌人行动。
- **有代价的知识**：常规工具有次数限制，禁忌能力以理智为代价，且主动支付不能被防护抵销。
- **航程叙事**：全部可玩空间都在海上与船上；调查船沿分支海图自动航行，不做驾驶、炮击或战棋走位。
- **公平边界**：不靠查询后重随机、无预告改答案、强制乱出牌等方式制造“疯狂”感。

## 三、功能说明

### 3.1 游戏流程

主菜单 → 选择初始船员（医师或听音员）→ 三幕航程（每幕实际访问 11 个节点，共 33 个）→ 幕末 Boss → 选择下一海域 → 终局结算。

| 模块 | 已实现内容 |
| --- | --- |
| 航海选路 | 分支海图、迷雾探索、6 种节点（普通战、Boss、事件、补给／整备、档案、独立奖励）；调查船沿曲线航行、镜头跟随与尾流，目的地在浓雾中逐渐显现 |
| 海域 | 五海域：灰雾航道（第一幕）→ 尸骸之海／倒悬潮庭／无灯裂海三选一（第二幕）→ 无星深渊（第三幕） |
| 回合制战斗 | 每回合抽 5、行动 3；生命与理智双资源；格挡与理智防护分别结算；拖拽出牌；敌人意图先锁定后展示可公开征兆 |
| 调查与知识 | 提灯、听筒、贝壳等工具回答限定问题；证据区分已观察、已验证、推测与未知，低可信度信息不覆盖已验证信息 |
| 卡牌构筑 | 96 张正式目录卡，分武装、防护、调查、干预、禁忌五类；行动簿收录已学卡牌，整备时编入 12 张不同卡 |
| 敌人与 Boss | 25 个普通遭遇；8 个规则各异的 Boss／目标战，如封线、存活撤离、按序封闭唱诗匣、盐格解谜、三阶段旗舰、召唤并击退五名守卫 |
| 船员与物资 | 最多 4 名船员，每场提供一次战斗支援，可招聘、营救、受伤与治疗；25 种物品与装备；档案与仪式 |
| 存档与续玩 | 航程检查点与局内战斗回放，原子写入并保留备份；退出后可从当前战斗原状态继续，不重掷开场 |
| 设置与无障碍 | 音乐／环境／音效分轨音量、显示模式、垂直同步、减少动效；重要征兆同时以文字呈现，不只依赖颜色或声音 |
| 视听表现 | 3D 调查船与海面反射、巨兽 Boss 分件骨骼动画与受击反馈、90 张卡面插画、四组三分轨同步配乐与环境音 |
| 发布 | 推送 tag 后由 GitHub Actions 构建 Windows x64 与 macOS 版本并发布 Release |

### 3.2 运行方式

- **试玩版本**：从仓库 Releases 下载 `UnsoundedSea-Windows-x64.zip` 或 `UnsoundedSea-macOS.zip`，解压运行（macOS 版本未签名，首次打开需在系统设置中允许）。
- **源码运行**：安装 Git LFS 后克隆仓库，用 Unity 6000.6.5f1 打开，点击 Play 即从主菜单启动。

### 3.3 操作

鼠标点击敌人切换查看对象；有目标的牌拖到目标上松手，无目标的牌向上拖出手牌松手。航海界面快捷键：M 海图、J 日志、B 行动簿、Esc 菜单。

## 四、原创说明

1. **原创内容**：游戏概念、世界观、海域与敌人设定、全部卡牌／物品／船员／Boss 机制与数值、关卡流程、界面设计，以及全部游戏代码与编辑器工具脚本均由团队原创。开发中使用了 AI 编程助手辅助编码，设计决策、整合、测试与验收由团队完成。
2. **原创音乐与音效**：四组配乐、枪声与巨兽声层、风声／尾流纹理及界面反馈音由团队用程序合成（`Tools/build_audio.py`），未使用外部乐器采样或付费服务；少量环境与打击素材来自 CC0 素材库并经剪辑、滤波和混合，详见技术文档。
3. **AI 辅助生成的美术**：卡面插画、补给场景图、游戏图标由图像生成模型按团队撰写的原创提示词生成；3D 角色、Boss、船只与地标由 Hyper3D Rodin 生成后，由团队完成减面、分件、骨骼绑定、动画与引擎接入。提示词、模型名称与文件哈希记录在 `ArtSource/` 下的 manifest 中。提示词未引用任何艺术家姓名或既有作品角色，只用题材与材质描述风格，并要求画面不含文字、标志与水印。
4. **第三方资源**：海面着色器（MIT）、CC0 音效素材、中文字体、Unity 官方包等外部资源均保留原始许可文件，逐项说明见 [技术文档与第三方资源说明](TECH_AND_THIRD_PARTY.md)。
5. **题材说明**：“克苏鲁”式宇宙恐怖为公有领域的文学题材类型；本作未使用任何受版权保护的既有游戏、影视或桌游中的角色、名称、美术或文本。
