## 1. 项目方向与本次范围

### 1.1 这是什么游戏

《未测之海》是克苏鲁调查题材的回合制卡牌构筑 Roguelike。调查员乘船进入无法被完整描绘的海域，利用手牌、工具和残缺证据，应对代理人、异常显现与仪式。

最重要的不是“看见怪物后把血条打空”，而是决定：

- 是否值得花资源确认一个危险；
- 是否可以不调查，用通用防护承担损失；
- 这回合应该输出、防守、处理召唤物，还是推进场景目标；
- 面对不能真正杀死的存在，怎样封住通路、完成取证或撤离。

画面仍为固定镜头 3D／2.5D 场景加二维卡牌界面。中央真实场景是主体，HUD 分布在四周；不把战斗做成铺满屏幕的数据面板，也不增加驾驶、实时闪避和战棋走位。

**世界空间约束：没有可登临陆地。**航程不设置岛屿、岸上港口、村庄或陆上遗迹关卡；所有整备、交易、招募、休整和调查都发生在船上、船间接驳或海面。小型怪物出现在船舱、甲板和被登临的漂流船；大型怪物在舷外海面显现，其小型召唤物可以登船。船体与海面共同构成战场，不增加驾驶、距离判定或实时舰炮系统。

## 2. 文档、代码和资产的事实基线

### 2.1 现有内容不是完整内容目标

最初原型包含 10 种卡牌、3 种工具、3 种敌人与 4 份遭遇配置。卡牌现已扩充为 [90 份资产](../Assets/UnsoundedSea/Content/Cards/)，以 `CardCatalog` 和第 5 节为准；[Tools](../Assets/UnsoundedSea/Content/Tools/)、[Enemies](../Assets/UnsoundedSea/Content/Enemies/) 和 [Encounters](../Assets/UnsoundedSea/Content/Encounters/) 的原型范围不因卡牌制作自动扩充。主线「雾海来客」及三维 Scenario 的入口见 [框架指南](FRAMEWORK.md#3d-战斗组合与扩展)。

- 保留稳定 ID 的原型十卡：左轮射击、寻找掩体、稳住心神、观察笔记、快速装填、临时照明、记录矛盾、直觉防护、撕毁符纸、应急包扎。
- 3 种现有战斗工具：防风提灯、定向听筒、听潮贝壳。现有四份遭遇装备的是提灯和听筒，贝壳有资产但没有被这四份配置装备。
- 3 种敌人资产：持刀走私者、蒙面祷告者、旧显示名“灯塔下的回声”。新版 B01 改称“漂灯下的回声”、迁至灯船；资产显示名与场景尚未随本文迁移，稳定 ID `echo` 保留。
- 4 份遭遇：公开意图、有限调查、封门目标、卡牌实验。它们是遭遇配置，不是四个完整三维关卡。
- 90 卡中的主动理智／生命支付、实例消耗、保留、回收、多目标、证据查询和场景干预已接入规则；不等于尚未接入的被注视事件分支或完整奖励经济已实现。

### 2.2 必须明确的设计与实现差异

| 内容 | 读取到的当前实现 | 本文采用的设计方向 |
| --- | --- | --- |
| 临时照明 | 不可观察且未知时不提供合法目标；已确认时抽 1 | 不让玩家为无法获得的信息付费 |
| 撕毁符纸 | 对存活目标先造成 4 伤害，再尝试打断 | 完整版保留这条直观规则；不额外加“普通敌人”分类限制 |
| 应急包扎 | 每张实例使用后消耗 | 明写为每张实例一次，不描述成同名牌全场共享一次 |
| 听筒 | 回答声源，不正式确认完整意图 | 保持局部查询；不能凭此触发“已确认意图”牌的奖励 |
| 听潮贝壳 | 回答伤害通道；不正式确认意图 | 保持有限问题；不充当万能揭示 |
| 回声区域 Boss | 旧资产两种行动随机选择、生命占位 999、封门目标 4 | 改为灯船舱内，采用公开四拍节奏与媒介切索路线 |
| 铜铃／显影粉 | 未见完整媒介、库存与切索实现 | 按机制文档作为待实现系统 |
| 血色启示 | C073 支付理智、记录实际威胁类别并抽牌；零伤害行动不伪报生命伤害 | 不查询雷位、完整唱序或隐藏对应 |

“撕毁符纸”保留先造成 4 伤害、再尝试打断的结算语义；目录规则已同步到 `CardCatalog` 和对应资产，仍不为普通伤害增加额外敌人分类限制。

### 2.3 航程选路的当前实现与边界

`VoyageMapGenerator`、`VoyageSession`、`VoyageRuntime`、`VoyageHud` 与 `VoyageSailingPresentation` 已接入 `Voyage.unity`。此节更新先前读取快照；规则接口、可见性和存档细节以 [框架指南](FRAMEWORK.md#航海选路局外) 为准，实际运行证据以 [验证记录](FRAMEWORK_VALIDATION.md) 为准。

- 方案 A 已接通三幕标准航程：灰雾航道 → 尸骸之海／倒悬潮庭／无灯裂海择一 → 无星深渊。每幕实际经过 11 节点，包含出发整备、四场普通战、事件、奖励、档案、两处中途整备和幕末 Boss；每局共 33 节点。
- 普通层分支概率、近邻连接、局部可见和三维航行沿用现有航图；旧海图和测绘望远镜各每幕两次，不因战斗刷新。没有陆地或登岸关卡。
- 25 个普通遭遇（五海域各五种）使用对应的独立静态敌人模型；每幕选四种不重复主敌人，第五种遭遇带一名本区精神威胁同伴。具体职责见[普通敌人目录](#72-普通敌人目录)。骨骼动画按当前制作范围暂缓。
- 普通战后三选一，独立奖励节点四选一；幕末先选下一海域、再按该海域三选一，终局直接结算。只投放未学方案，也可放弃换补给，不提供刷新；奖励页可只读查看行动簿。在每幕出发与整备节点，从本局已学方案中编入 12 张不同牌，选择至多两件战斗工具。
- 生命、理智、补给、船员与构筑跨战斗保留；三类确定性海上事件、航路抄录和 Boss 机制简报已接入，知识写入日志并随存档重放。航程存档包含未结算战斗回放，可中途保存返回并继续，而非从战斗起点重开。
- 主页只保留统一调试选关，不再单列 Boss。五海域专属环境、下文候选独立剧情、完整 25 道具库存、装备被动及船员招聘仍是提案。地图与检查点为第 5 版，旧档不迁移、不因加载失败被覆盖。

## 3. 共用规则与术语

本节中沿用的基础规则以当前框架为依据；解谜、召唤、装备和扩展卡的规则属于提案。理智的航程压力、船员组成与招募统一见 [理智与船员设计](SANITY_AND_CREW_DESIGN.md)，此处不建立第二套规则。

### 3.1 基础行动经济

- 起始参考资源：60 生命、30 理智；每回合 3 行动、抽 5 张。
- 格挡只抵扣敌方生命伤害，理智防护只抵扣被动理智冲击；二者在下一回合开始重置。
- 主动支付理智绕过防护，支付后至少剩 1 点。生命或理智耗尽即失败。
- 敌人先锁定行动，再交给玩家决策；调查和查看记录不重抽答案。
- 解谜操作、处理召唤物和出牌共用 3 行动，不能无限免费点击谜题获得进度。
- 允许免费阅读、选择目标和记笔记；只有会改变知识、资源或任务状态的操作才检查次数与代价。

### 3.2 本文卡牌术语

| 术语 | 精确定义 |
| --- | --- |
| 费用 | 行动费用；额外理智或生命在效果中另写 |
| 消耗 | 这张卡牌实例本场使用后不再洗回牌堆；不是同名所有副本共用一次 |
| 已确认 | 系统正式确认的目标本回合意图；声源推理不自动满足 |
| 已验证连接 | 有本场有效证据的“召唤物／媒介—锚点”关系，不等于知道异常本质 |
| 普通目标 | 可承受普通伤害的敌人或召唤物；不包括无实体的最终存在 |
| 召唤物 | Boss 行动创建的敌方单位；有独立实例、生命、意图与来源 |
| 保留 | 被指定的牌跳过本次弃牌，留到下回合；没有再次获得保留就正常弃置 |
| 延缓 | 指定的、明确标为可延缓的倒计时增加 1；不是让整个 Boss 跳过所有行动 |
| 场景行动 | 一类任务效果，不再等同于固定按钮；B02–B05 由首回合发放的遭遇牌承载，费用、目标和共享次数见 8.1；B01 原方案暂不迁移 |
| 阶段取消 | 明确被规则取消的旧威胁才消失；普通阶段演出不暗中清空已锁定攻击 |

新增效果如减少待结算冲击、保留、检索牌堆、改变任务时钟，都需要独立实现与验证；不能因为基础效果注册表有 `draw`、`ward` 就宣称已经支持。

### 3.3 解谜的公平边界

1. 谜题答案在开战时确定，可被存档和回放恢复，不因玩家点错或查询而改变。
2. 信息不足时必须有不猜的路线：首回合必得且可重复使用的遭遇牌、已公开约束或可承担的防护路线，不能要求恰好抽到唯一卡牌。
3. 需要先判断后尝试的操作，提示总费用、最大失败伤害和是否消耗次数。
4. 错误可以造成公开的资源损失或延误，不默认“一次点错整局立即失败”。
5. 不将完整扫雷棋盘、连线谜题和五种召唤物同时塞进同一阶段；每阶段突出一个问题。
6. 卡组能改变解谜速度和承伤，而不是解谜时牌组被完全停用。
7. 不用改变费用、故意错字、误导按钮、强制乱出牌来表达疯狂。

### 3.4 召唤结算契约

提案统一为：本回合预告召唤 → 敌方结算时创建单位 → 下一个玩家回合显示完整可用征兆 → 新单位最早在下一次敌方结算攻击。

- 场上活动召唤物上限默认 2，最终 Boss 特别阶段可提高至 3，并在入场时明示。
- 满额时的召唤效果必须写明：默认不新增，也不暗中转化为额外伤害。
- 召唤来源被打断时只取消尚未发生的那次召唤，不删除已经存在的单位。
- 击杀、封缚、消散是不同结果；只有符合目标条件的结果才发放一次性任务进度。
- 场景已完成的锚点不能再次召唤同一守卫、重复领奖或被后续随机数重新开启。

骨片侍从、雾灯蛾群、空甲执旗兵及五类航标守卫的伤害攻击均标为可封缚；封缚只取消所选单位本回合的攻击，不取消治疗、召唤、休眠复现、本体余响或场景警报。公开的守卫—航标对应直接满足牵引条件，不再收取一次“正式验证税”。

## 4. 五个海域与场景内容

### 4.1 海域递进总览

| 海域 | 来源 | 情绪与场景主调 | 本区主要新问题 | 目标敌人 |
| --- | --- | --- | --- | --- |
| 灰雾航道 | 修订原灰雾海域 | 补给母船、漂流货船、灯船舱室；日常秩序出现缝隙 | 公开意图与双候选，调查不是必选 | 区域 Boss：漂灯下的回声 |
| 尸骸之海 | 原概念海域的海上化 | 漂骨、标本船、祷告船；巨型鲸骸在舷外发声 | 多目标、召唤来源与媒介 | 区域 Boss：骸潮领唱者 |
| 倒悬潮庭 | 本文新增 | 颠倒的船影、测量船、船上盐格盘 | 扫雷式局部约束、行动分配 | 区域 Boss：倒悬司衡者 |

这是完整内容的地理与机制目录，不要求每局按固定五连战运行。优先以“选定海域／航程长度”组织测试，待节奏成立后再决定完整串联方式。

### 4.2 灰雾航道：世界仍大致可信

**场景组。**灰雾补给母船承担出航整备与招募接驳；调查船餐舱承担船员事件；走私货船甲板用于公开攻击教学；废弃无线电舱提供重复求救；无声灯船下层舱室作为首个完整战斗样板。进入其他船只通过短接驳过场，不增加自由探索与驾驶。

**环境细节。**木板盐霜、潮湿缆绳、船籍编号、过期航表和不一致的值班日志。异常集中在具体物件，不让每个箱子都发光。

**敌人与路线。**走私者和祷告者都在船上；事件线索可帮助理解灯船铃组，但不决定是否能接驳灯船。补给母船也漂在海上，不用“港”字暗示一座未画出的陆上城市。

**奖励方向。**基础攻击、防守、可见动作调查和小额续航。玩家先学会可靠读牌，不急着引入复杂禁忌链。

**区内解谜。**比较两份航海日志、确认声源、找出连接铜铃；不是密码锁连续套娃。

### 4.3 尸骸之海：谁在发声比声音内容更重要

**场景组。**成片漂浮鲸骨、标本船半淹货舱、漂流祷告船、舱内小礼拜室、绑在船舷的三座唱诗匣。领唱者的巨大鲸骸在海上，骨片侍从和信使出现在船上，不把漂骨堆变成可行走岛屿。

**环境细节。**海洋标本有错误的关节，漂流船的祷词和船员嘴型不一致。骨材是风化遗存，不以血浆覆盖场景。

**玩法。**引入“召唤者、召唤物、媒介”的区别。打倒祷告者未必等于拆掉正在运作的唱诗匣；拆匣也不会自动消灭所有独立实体。

**奖励方向。**群体小伤害、打断、清理召唤、追踪来源。调查收益是更有效的目标顺序，而不是直接免除战斗。

**风险递进。**敌方单位更多，但同屏活动召唤上限仍小；界面需要展示总待结算威胁，不让两只小怪藏在主 Boss 背后。

### 4.4 倒悬潮庭：在可计算的异常中行动

**场景组。**船影倒置的测量海域、漂浮测量船、反射观测舱、嵌在船上测量甲板的四乘四盐格盘、悬吊测深仪。“潮庭”是仪器与海面形成的异常景象名称，不是一座陆上庭院。

**环境细节。**海面中的船影方向矛盾，但真实甲板、可操作格盘、格子编号和文字始终稳定。不要翻转整个 HUD；大型司衡者在舷外海上露出局部，蛾群在甲板上活动。

**玩法。**以扫雷式相邻数量为主要语言：数字只回答附近有多少危险，不回答它们的来历。玩家一边防守，一边开放安全石板和激活封栓。

**奖励方向。**局部查询、保留、低费防护、场景行动减费。奖励不能变成“没有扫雷牌就不能过关”。

**生成边界。**先做经过验算的固定版面与少量变体；未实现无猜测验证之前，不使用任意随机雷区。

### 4.5 无灯裂海：设施运转不等于设施为你工作

**场景组。**熄灯舰队甲板、浮动修理船、旗舰装卸机舱、三段水密闸廊、断裂信号桅。没有干船坞和岸上基地，修理与交易都通过船间接驳完成。

**环境细节。**旧军用铜器、浸水旗帜、断裂吊架与一次只照亮局部的灯光。远处舰队构成压迫背景，不作为可操控海战单位。

**玩法。**先启动装置创造窗口，再处理一段承压操作，最后抓住窗口输出。借用团本“职责切换”的节奏，但所有决策都发生在回合内。

**奖励方向。**保留爆发、对已确认目标输出、推迟特定警报、应急防护。任务进度牌能省一步，不能跳过整场 Boss。

**失败边界。**装置不会因一次误触永久损坏而软锁；恢复装置要付行动，且后果明确。

### 4.6 无星深渊：不需要杀死王座上的存在

**场景组。**重复出现的船舱、仿佛没有尽头的船列、五座漂浮航标、海面王座投影、船上撤离绞盘。

**环境细节。**熟悉船体以不合理比例重新出现。王座并非可登上的实体岛台；巨大存在只在海面和雾中展示局部轮廓，五种人形守卫则在调查船甲板上显现。

**玩法。**最终目标是封闭联系并带走证据。召唤物与锚点有确定对应关系；错误处理造成可预告的复现，不让玩家靠无限杀怪刷奖励。

**奖励方向。**完成航程、解锁已验证条目和新内容入口，而不是永久叠加大量生命攻击。

**结局表述。**“你切断了它与这片海域的几条联系”，不是“你杀死了宇宙级存在”。

### 5.7 发放与构筑原则

90 种是跨场景目录，不是每局全量随机池。正式航程按公共／当前或下一海域牌池发放未学方案，奖励只加入本局行动库；整备点再选 12 张不同牌，不能将新牌强制塞入牌堆。可放弃卡牌换补给，无免费刷新。当前分配与存档接口见[框架指南](FRAMEWORK.md#航海选路局外)；按已验证记录解锁奖励池、物品奖励和稀有度经济仍未实现。

### 5.8 初始调查包：12 张不重复的行动方案

不沿用旧原型用多张相同射击和掩体填满牌堆的方案。初始包每张只有一份，目的是让玩家从第一场就同时拥有观察、判断、处置、护持与准备，而不是先玩若干场基础攻击换高级攻击。

| 职责 | 初始方案 | 张数 | 为什么带上船 |
| --- | --- | ---: | --- |

| 自我维持 | C019 寻找掩体、C020 稳住心神、C021 直觉防护、C022 应急包扎 | 4 | 针对防护、未知兜底和有限医疗 |
| 现场调查 | C037 观察笔记、C039 临时照明、C041 听声辨位 | 3 | 记录、确认可见动作、获取局部声源 |

这 12 张共享原型每回合抽 5、3 行动的预算，但不承诺任意抽牌都能无伤。第一次教学明确呈现生命／理智／未知三种情况；实际初始手牌的失败率和各 Boss 资源下界需要运行验证。

必要操作不抽牌：绘线、开格、测读、牵引、绞盘始终由场景提供；船员支援也有独立按钮。失去某一张调查牌不会让这一局不能继续。起步工具选择和初始船员详见 [理智与船员设计](SANITY_AND_CREW_DESIGN.md)。

成长采用“整理行动簿”：在安全整备点把学到的方案编入或换出，不要求每次获奖都永久扩张牌堆；已学方案保存在本局行动簿，不因暂时换出而销毁。普通方案默认编入一份，消耗只影响本场实例。首轮不做任意删牌收费、随机职业牌池和数字升级树。

这仍是回合制抽牌系统，但构筑目标转为“为下一片海域准备哪些处置手段”。配装、船员和证据共同改变适用场景，不把卡组当成全部角色成长的唯一容器。

## 6. 25 种道具：工具、消耗品、装备

### 6.1 分类与装备边界

工具独立于牌堆。战斗工具沿用最多装备两件不同物品；航行工具不占战斗槽，也不因进入战斗重置航程次数。

装备是调查员携带的具体器物，不作为神秘收藏品统称；当前九种候选使用被动效果，提案每航程最多装备三件、遭遇前更换。效果来自器物用途或明确的异常联系，不随物品数无限叠加；同名副本不重复触发，不做随机词缀。

召唤物是普通敌人的来源与行为标签，不是第四种敌人等级。若第五海域需要一个独立的区域 Boss，应另行设计并评估总数；本文不偷偷把同一个 B05 算两次。

M02–M05 的运行构图以「沉钟海域」为尺度参照：原尺寸调查船位于前景，远处巨型本体占据天空和海平线；不再把 Boss 缩成船边的普通敌人。镜头不必囊括全部轮廓，但主要识别部位、机关目标和召唤物操作必须清晰。此项改变表现尺度，不擅自提高生命或伤害。

#### B02–B05 共用遭遇牌契约

用户所称 M02–M05 对应本文稳定编号 B02–B05，不另建一套 Boss。四场核心阶段与首回合遭遇牌已接入 Unity 独立场景，入口和接口见 [框架指南](FRAMEWORK.md#m02m05-特殊-boss-战)。以下仍是完整内容目标；90 张构筑牌、装备联动及五海域主线不因四场可运行而视为已完成。Boss 模型单独生成，场景复用现有水面与调查船。

- **发牌**：第一玩家回合正常抽 5 张之后，Boss 遭遇事件直接授予本场全部专属牌，每种一个稳定实例；不消耗抽牌、不触发抽牌奖励，不计入 90 张构筑牌。它们与普通手牌共用扇形牌面、费用和目标操作，不另加机关按钮栏。
- **不会丢失**：遭遇牌永久保留至职责完成或战斗结束，不进入抽／弃／消耗堆，不计普通手牌数量；普通弃置、复制、检索、消耗、移除与随机选牌效果只处理普通牌。使用后仅扣共享次数；本回合仍有次数则留手可用，否则牌面标“下回合”。一次性职责完成后移除，不能回收刷进度。
- **阶段**：后续阶段的牌也在首回合发放，公开显示解锁条件，尚未解锁时不可用；转阶段不额外发牌、恢复行动、刷新次数或洗回消耗牌。重开新战斗重建实例；同一战斗恢复不得重复授予。
- **费用与配合**：仍共用每回合 3 行动。遭遇牌具有“场景行动”标签，C024、C029、C031、C064、C071、I19 等按原文字作用于它；C064 仅减一次费用，不增加次数。相同工序的常规与构筑牌入口共享次数，只有明确写“不占常驻次数”的 C065、C067 等例外保留其耗费与消耗限制；C072、C086、C087 不绕过 Boss 阶段、锚点或专属次数。
- **出牌**：选牌 → 选场景目标／同一目标的键盘焦点 → 确认出牌；多目标依次选择，Esc／右键免费取消。只在最后确认时校验并扣费；失效目标、重复完成、条件不满足不扣费。允许冒险的封匣／开格，在牌面预览显示明确风险，不能用后台答案决定高亮。
- **显示**：遭遇牌用黄铜任务角标与明确名称区分，不靠颜色；保持右牌覆盖左牌。机关只承担目标与状态显示，点击机关本身不执行付费动作。免费查看证据和标记不变成收费卡；威胁用短句分行，不再增加大段常驻说明。
- **结算**：每次出牌完整结算费用、效果及死亡，再检查胜利；本体和旧召唤物按已公开顺序行动，警报随后结算，新召唤／复现最后入场且当次不攻击。新单位至少留一个完整玩家回合应对；阶段取消哪些威胁必须逐场明写。所有答案、阶段、次数、首次出现标记与休眠期限可确定性恢复。


### 8.2 B01：漂灯下的回声——保留原有的第一课

**场景。**约 8×8 米的灯船下层舱室，舱内浅水、船壁、三只铜铃、空潜水服与隔舱门。潜水服在中上部，铃组装在舱壁，封线围住舱门四处缺口；这是船上空间，不是海中出现一块陆地。

**目标。**封门 4／4。显现体不展示 999 占位生命作为战斗目标；普通射击不让玩家产生“只要打得够久就能弑神”的误解。

**公开节奏。**四拍循环：8 生命、4 理智、8 生命、4 理智。每拍具体威胁公开，连接铃身份仍可未知。

**常驻行动。**绘制封线：1 行动、每回合一次、进度 +1；不要求手牌、工具或隐藏条件。

**调查捷径。**听筒确认声源是舱壁铃组；显影粉可直接验证连接铃，不以听筒为前置。切断铃索：2 行动、本场一次、要求已验证连接；取消当前与后续铃鸣，并封门 +1。

**两条基础路线。**不使用额外任务进度牌时，不调查可四次绘线；调查后可在第二回合切索并绘线、第三回合完成。任务构筑允许进一步提速：封门仪轨独立推进，但不取消铃鸣；切索和破坏媒介共享媒介状态和一次性收益。

**可计算下界。**采用本提案四拍节奏、从 60／30 满资源进入且完全不防护时，前三次结束回合承受 8 生命、4 理智、8 生命；第四次绘线先获胜，剩 44／26。这是设计算例，不是当前随机 Boss 的运行结果。

**演出。**胜利锁定后潜水服塌落，隔舱壁后的余响继续。无需再添加一波小怪填充回合，首个区域 Boss 的任务是证明非击杀目标成立。

### 8.3 B02：骸潮领唱者——封匣与清召唤交错

**目标与场景。**玩家在漂流祷告船甲板，舷边三座独立唱诗匣标“潮／骨／息”；舷外是约 18 米长的鲸骸代理。先按顺序关闭三匣，再击破 36 耐受的发声囊迫其沉退。护持期普通伤害最低压至 1，伤害保留；不把整头显现体当作厚血条。

**首回合遭遇牌。**

| ID／牌名 | 费／次数 | 目标、效果与退场 |
| --- | --- | --- |
| E02-01 聆听唱序 | 1；有新约束即可再用 | 无目标；公开下一条未公开的顺序约束。无新约束时禁用；完整顺序已知后移除 |
| E02-02 按序封匣 | 1；全场景每回合一次尝试 | 选一座未关闭匣。正确则永久关闭；错误则承受 4 理智冲击，可防护，不回退已关闭匣。两种结果都耗本次额度；三匣全关后移除 |

**信息公平。**开战用遭遇种子从六种排列锁定答案。第 1 回合公开“第一项在第二项前”，第 2 回合公开“第二项在第三项前”；两条约束唯一确定排列。聆听可提前取得下一条，之后自动公开时跳过已知项，无重复收费。已有事件档案只提前公开同一事实，不替玩家关匣。不要求辨别音高；文字、浮雕与声音表达同一条可知信息。尚不确定时仍可选择任一未关匣，不能靠可用性探答案。

**威胁。**第一阶段循环：回合 1 预告 6 生命，回合 2 预告召唤骨片侍从，回合 3 预告 4 理智。侍从 8 生命，下一完整回合起每回合 3 生命攻击。第六回合之后的召唤拍，无活动信使时优先召唤潮囊信使，否则尝试侍从；两类合计最多 2。信使 10 生命，从首次可行动回合起每回合预告恢复发声囊 6，最高 36；治疗可打断，不复活已败 Boss，不重开匣子。召唤拍允许普通打断和禁忌干预；满额不转伤害。

## 9. Hypixel SkyBlock M7 参考研究与改编

### 9.1 来源与可信度

这里的 M7 指 Hypixel SkyBlock 的 Master Mode Catacombs Floor VII。资料读取自社区 Wiki 的 [Floor VII](https://hypixelskyblock.minecraft.wiki/w/The_Catacombs_-_Floor_VII) 和 [The Wither King](https://hypixelskyblock.minecraft.wiki/w/The_Wither_King)。这是机制资料研究，没有登录服务器实测，也不把社区文字当作本项目已实现行为。

原官方 Wiki 地址读取时转向 [Hypixel 关于关闭官方 Wiki 的公告](https://hypixel.net/threads/end-of-the-official-hypixel-wiki-july-2026.6112020/)。因此本文明确使用社区资料，不把它误标为现行官方机制手册。

### 9.2 实际借鉴的结构

| M7／F7 内容结构 | 来源描述的核心 | 对《未测之海》有用的抽象 | 本文落点 |
| --- | --- | --- | --- |
| Maxor 阶段 | 收集能量水晶、启动光束并创造受伤条件 | 先做场景任务，再把伤害转化为有效推进 | B04 继电器 |
| Storm 阶段 | 利用柱体与对应机关压制 Boss | 环境不是布景，而是可读的战斗工具 | B04 装置条件；不搬实时引怪 |
| Goldor 阶段 | 一边面对追近压力，一边完成终端、装置和开关 | 解谜与防守共用时间／行动预算 | B03 扫雷、B04 闸廊 |
| Necron 阶段 | 相对直接的持续输出与生存检验 | 复杂工序后给牌组输出一个明确兑现阶段 | B04 最后阶段 |
| M7 额外王座阶段 | 收集对应仪式物件开启阶段；五种龙在对应雕像附近被击杀才完成雕像目标 | Boss 本体可以不可伤害；击退召唤物还需满足对应关系 | B05 航标守卫 |
| 王座阶段召唤压力 | 雕像未处理时龙可再次出现，多龙共存有强惩罚 | 未解决来源会复现；处理正确对象带来永久进度 | B05 休眠、复现与锚点关闭 |

前四段是 Floor VII 的整体 Boss 结构，不是 M7 独有；第五阶段才是这里重点使用的 Master Mode 差异。社区资料对王座初始双龙和后续生成有更细描述，本文不依赖具体实时秒数，不据此复制一套计时脚本。

### 9.3 不照搬的部分

- 不复制名称、角色、美术、台词、地图和数值。
- 不复制多名队员同时跑终端、踩机关、拉怪的操作负担；单人改为分回合选择职责。
- 不复制即时站位判定；“在对应雕像附近击杀”转为显式牵引绑定关系。
- 不复制颜色作为唯一答案；形状、铭牌和文字一起使用。
- 不复制极端伤害与一次失败整局作废；提供已预告的承伤、延误和重试成本。
- 不把纯熟练度终端照搬成独立窗口。谜题保留在三维场景中，手牌仍在同一回合可用。

M7 参考的价值不是“五个阶段越多越好”，而是**不同阶段轮换考验任务、机关、承压和输出，召唤物的正确处置能改变永久目标状态**。

## 10. 调查事件、奖励与构筑路线

### 10.1 原有两个事件的完整职责

**第十三名船员。**十二人船上有十三份用过的餐具。

- 对照值班日志：花 1 补给，得到名字线索，可信度为推测。
- 安排临时隔离：无资源代价，记录关系变化，未验证身份。
- 留下并观察：获得 1 补给，明确增加被注视 1，提示后续关注。

它讨论“如何应对尚未证实的异常”，不在插画中提前把某个船员画成怪物。被注视尚未接入事件后果时，只记录，不追加未预告伤害。

**重复求救。**旧无线电播出不同人记得不同内容的求救信号。

- 对照两份抄报：得到铃节奏传闻，只提示可以检查铃组。
- 花 1 补给校准：在维修柜中找到 1 份显影粉，不是无线电凭空制造粉末。
- 封存无线电：无收益、无额外惩罚，仍能接驳灯船走四次绘线路线。

这两个是已有细化设计，不是当前航程 Event 节点已经落地的多选剧情。

### 10.2 五海域的新增事件候选

| 事件 | 海域／问题 | 明示选项与代价 | 结果边界 |
| --- | --- | --- | --- |
| 漂流中的旧锁箱 | 灰雾；打捞后取物还是省补给 | 花 1 补给开锁得备用弹匣；或放回海面 | 全程船上操作，不强制新增战斗 |
| 错误标本 | 尸骸；是否核验分类 | 支付 2 理智核验得本区来源档案；或封箱无收益 | 档案只解释已核验的标本关系 |
| 没有嘴的合唱 | 尸骸；处理哪处声源 | 花 1 补给拆开唱诗匣，得一条 Boss 顺序约束；或记录传闻 | 不提前关闭 Boss 场内匣子 |
| 倒着写的测量簿 | 潮庭；证据还是物资 | 花 1 补给获得黄铜探针；或拿走 1 份清醒盐 | 不出售唯一通关工具 |
| 无人认领的灯号 | 裂海；修复还是拆取 | 花 1 补给得绝缘钳；或获得海标烟罐 | 提前显示两种适用场合 |
| 旗帜上的旧编号 | 裂海；确认实体关系 | 支付 2 理智得执旗兵来源证据；或不追查 | 不自动给当前敌人意图确认 |
| 回到同一张餐桌 | 深渊；辨认重复还是保持距离 | 消耗一份医疗敷料得本场一组锚点证据；或离开 | 不把船员身份升级为已验证真相 |
| 最后一段归航绳 | 深渊；取回还是补给船员 | 花 1 补给得救生牵引带；或恢复 3 理智 | 选择前说明装备只服务撤离目标 |

补给数量与节点交换已经接入航程；上述依赖具体物品的候选分支，仍须等待库存、装备和读档去重实现，不能视作当前可运行事件。

### 10.3 奖励要让路线成立

当前奖励执行普通战后三选一、独立奖励四选一、幕末选择下一海域后三选一；终局 Boss 直接结束航程。信息节点提供航路或机制知识，不再全部换算为补给。区域 Boss 的装备／工具／区域档案奖励、商店价格与卡牌稀有度仍属后续经济提案，不能与当前已实现的行动库混称。

五类可混合构筑：

- **确认输出：**临时照明、记录矛盾、确认弱点、盐蚀怀表。花机会取得可靠高伤害，但听筒推理不误触发条件。
- **稳健作业：**直觉防护、背靠实墙、绘下界线、测量罗盘。保守应对并稳定推进谜题，不要求完成所有调查。
- **召唤清理：**近距霰击、驱散弹幕、追踪召唤、绳钩腰带。清小怪和关来源，但最终 Boss 仍需要牵引关系。
- **预备处置：**双份抄录、校正航记、压舱重击、备用弹匣。利用空档整理手牌，在装置开放后兑现。
- **禁忌交换：**黑潮穿刺、失眠守夜、深水回读、铅衬笔记匣。理智换效率，不能把主动支付变成可免除的免费循环。

这些是设计组合，不是已经打通五海域的实测推荐牌表。

## 11. 场景、美术、声音与交互要求

### 11.1 三维场景必须承载玩法

每个 Boss 空间至少有一个真正参与规则的组件：铜铃、唱诗匣、盐格、继电器／闸锁、航标。它们不是装饰性点击物；状态必须对应 Session 中明确的规则状态，而不是场景脚本自行推断隐藏意图。

- 中央大部分面积保留场景与敌人轮廓；底部牌区、左右信息和顶部资源不能把它遮成背景壁纸。
- 重要交互物件在固定镜头与窄窗口中仍可识别；同时提供文字目标列表。
- 不把微小三维点选作为关键操作的唯一入口；卡牌目标、格子坐标与场景行动都支持键盘焦点。
- 三维动画可以表现靠近与牵引，但不悄悄产生实际距离、闪避率和射界规则。

### 11.2 三种不同的美术层

**环境。**海墨蓝、雾灰、潮湿船木、盐蚀金属和有限暖光；远处始终是海、雾或其他船体，不用岸线作构图支撑。暗部保留材料层次，不能为了克苏鲁气氛把字和牌一起压暗。

**人物与道具。**铜、蜡布、皮革、盐结晶与真实重量。祷告者的刀和小铃在未确认时不露答案；两种隐藏意图共用姿态、声效、光泽和附件可见性。

**玩家界面。**航海档案纸张、铜标签、清晰字形。费用、额外支付、精确效果、次数置于稳定位置，装饰不能侵入规则文字。

### 11.3 卡牌与物品素材工作量

90 种牌是规则目录，不等于立即订购 90 张完成插图。先让每个构筑方向有一张可代表它的高完成度牌，再扩展共用框架和图标。

场景专用牌优先复用对应空间的已制作物件作为画面主体；可以保持美术语言一致，但不能把同一幅图改色当作完全不同规则的唯一识别。

25 种物品先保证图标与用途清晰。只有需要近距离交互的提灯、听筒、探针和关键媒介优先制作三维模型；医疗敷料、茶包、拓片等可以先使用清楚的二维物件图。

### 11.4 声音和信息边界

声源方向是听筒机制的一部分，但必要结论一定同时以文字出现。关闭声音后，玩家仍可获得同等策略信息。

理智攻击的失真效果不得遮费用、格盘数字、目标列表和结束回合。可减少画面扰动；异常不能改变鼠标命中区或把按钮移走。

### 11.5 状态提示必须回答四个问题

1. 我现在面对什么威胁？
2. 我实际已经知道什么，哪些只是推测？
3. 这个按钮会花多少资源、改变什么？
4. 失败、召唤、复现或转阶段以后，下一步还能做什么？

档案可展开回看，不常驻铺满战场。揭示连接、切断媒介、击退守卫和关闭锚点先更新规则，再播放效果；胜利锁定后才播放终局演出。

## 12. 落地顺序、验收边界与来源

### 12.1 先证明三种不同的 Boss 决策

**第一步：补齐灯船样板。**实现四拍策略、媒介状态和切索；验证不使用额外任务牌时的四回合绘线与三回合调查路线，再单独验证任务构筑提速。把现有一个船上区域 Boss 与灯船舱室做成可信视觉样板。

**第二步：验证战斗中扫雷。**只做本文一个经过验算的版面、一种蛾群和少量辅助牌。观察玩家是否在防守、清怪、开格之间真正改变选择；如果只机械点击安全格，应先改行动压力，不扩大棋盘。

**第三步：验证对应召唤。**先用三种航标守卫验证牵引、击退、复现、永久关闭与回放；最终内容目标仍是五种，不把三种验证版冒充完整 B05。

**第四步：补齐航程资源与奖励。**在现有航程选路、场景往返与存档上补齐资源继承，再加入库存、选卡、装备、事件和档案结算；未接好时不报告完整 Roguelike 已成立。

**第五步：扩至全部目录。**按构筑包逐步制作剩余卡与道具；B02 和 B04 复用已验证的召唤、机关与阶段机制，不各自再建一套规则层。

### 12.2 核心验收清单

- 卡牌目录准确为 90 种，道具为 25 种；原 18 卡全部保留且明确状态，不把副本算种类。
- 五海域的规则、环境和目标有区别，不只是同怪换皮与血量递增。
- 同种子调查与不调查不改变实际意图、雷位、连接铃、守卫对应和召唤顺序。
- 听筒答案不能误激活正式确认收益；过期情报不再满足本回合条件。
- 无效命令不扣行动、理智、物品或次数；主动支付不能被防护抵免。
- 召唤物有上限、新出现单位有应对窗口；满额和复现冲突不产生隐形第四单位。
- 解谜不以工具、特定卡或随机抽牌作为唯一通关钥匙；每个固定版面分别验证无猜测路线。
- 转阶段不重复结算旧威胁，不重发一次性收益，不清空应继续存在的召唤物。
- 读档恢复谜题、媒介、封缚、休眠、倒计时、使用次数与奖励状态，不能换答案或重复领奖。
- 1920×1080 和较小窗口中场景仍是主体，牌面、坐标与精确规则清楚；关闭声音和扰动后仍可操作。
- 完整流程需要实际运行、交互与目标设备检查，本文内容完整不代表上述游戏验收已经通过。

### 12.3 本次研究完成了什么、没有证明什么

已完成文档研究、M7 资料阅读，以及 B02 六种唱序唯一解、B03 指定棋盘的无猜六步和 B04 五回合机关路径验算。B02–B05 的首回合遭遇牌、核心阶段、模型和镜头已接入 `BossM02`–`BossM05`；主菜单统一「调试选关」可独立进入，正式三幕航程调用同一套规则。规则测试、实际通关与 UI 操作证据见 [验证记录](FRAMEWORK_VALIDATION.md)。当前已经接入 90 卡、25 种普通敌人和行动奖励，但不代表全部候选物品、剧情、构筑联动或长期平衡验收。

M02–M05 已由 Hyper3D Agent 生成，高模与减面版保留于 `ArtSource/Bosses/`，减面版同时导入 Unity 并建立 Prefab。M03 已重新生成，M04 在新项目中重试成功。来源、规格、哈希与导入路径分别见 [M02 manifest](../ArtSource/Bosses/TideBonesChoirmaster-manifest.json)、[M03 manifest](../ArtSource/Bosses/InvertedSurveyor-manifest.json)、[M04 manifest](../ArtSource/Bosses/UnlitFlagBearer-manifest.json)、[M05 manifest](../ArtSource/Bosses/StarlessWatcher-manifest.json)。四者均检查了实际战斗镜头；M05 兜帽轮廓仍偏人形，未作美术定稿。完整多视角、骨骼动画、独立 Player 与目标设备性能均未验收。

卡牌伤害、道具次数、海域顺序与 Boss 回合目标均为可讨论的平衡基线。最主要风险是多阶段 Boss 挤占卡牌构筑的存在感，以及五海域同时制作带来的场景成本；验证应围绕这两点，而不是先把 90 张卡全部画完。
