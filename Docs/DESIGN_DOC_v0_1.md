# THE UNSOUNDED SEA《未测之海》

原型概念版本 v0.1 · 2026-10-16。克苏鲁调查题材、回合制卡牌构筑 Roguelike；Unity，固定镜头 3D 场景与 2D 卡牌 UI。本文维护产品方向、世界观、原始 18 卡与 MVP 范围，数值均为待测试草案，不代表完整内容版的最终规模。

完整内容目标与修订后的卡牌方案见 [内容扩展设计](CONTENT_EXPANSION_DESIGN.md)；理智与船员见 [专门设计](SANITY_AND_CREW_DESIGN.md)。共用机制与美术规格见 [机制与素材设计](ASSET_MECHANICS_DESIGN.md)；已实现功能见 [框架指南](FRAMEWORK.md)。新增方案必须区分提案与实现。

## 核心体验与范围

调查员乘船深入地图与现实逐渐失效的海域。玩家能看见敌人行为的征兆，却不天然知道完整意图；借助工具、档案和禁忌物品取得局部信息，再根据手牌与资源应对。目标是在不完整知识下活过遭遇，完成阻断、封印或撤离等局部胜利。

- 卡牌优先：规则可读、费用可靠、有规划与组合空间。
- 有限认知：未知必须有征兆或可通用防护的路线；调查回答限定问题，不能变成每回合必缴的信息税。
- 有代价的知识：常规工具消耗次数或机会，禁忌能力可以支付理智与明确的后续代价。
- 航程叙事：船是营地与章节舞台；不做驾驶、炮击射界、实时闪避、战棋或自由走位。
- 公平边界：不靠查询后重随机、无预告改答案、强制乱出牌或随机改费用制造“疯狂”；不用普通血条代表可杀死宇宙级存在。

## 航程与战斗循环

调查船整备 → 分支海图 → 战斗/调查/事件/交易/休整 → 卡牌、工具、档案、补给奖励 → 路线抉择 → 区域目标战 → 下一海域或结局。船自动节点航行；所有可玩空间都在调查船、灯船、补给母船、医疗船、接驳船、救生艇、漂浮测量船、沉船或敌船上，不登陆港口、岛屿、村庄与岸线。

完整内容目标调整为五海域，详见内容扩展设计；原型仍先验证 5–6 节点、10–15 分钟。原正式版 45–70 分钟仅为旧时长设想，五海域版本须重新测定。巨大怪物与大型区域 Boss 在海上呈现，小型普通敌人与召唤物登船交战；船员以支援和事件选择呈现，不增加驾驶、炮击射界、实时移动或多角色战棋操控。

每回合基础抽 5、行动 3；敌人先锁定行动，再展示允许公开的征兆。玩家选择调查、出牌或推进任务，结束回合结算敌方行动。最多装备两件不同主动工具；普通敌人可直接公开意图，需调查的普通敌人先只隐藏一个关键维度。完整内容只使用普通敌人、区域 Boss 与 Boss 三层分类。

调查后精准应对、通用防护与主动承担风险都应可行。打断、阶段切换等改变敌方行为时必须明确提示；查询本身不重抽行动。

## 信息与资源

| 信息 | 获取与展示原则 |
| --- | --- |
| 自身资源、费用、规则 | 始终准确、公开 |
| 姿态、声响、可见装备 | 直接现象，不故意遮蔽普通观察所得 |
| 当前意图 | 公开或展示候选；调查只揭示限定字段，当前确认有回合有效期 |
| 异常规律 | 通过档案与验证获得；已验证内容可查，避免重复猜测 |
| 本质与来历 | 可留白，不等于操作规则不透明 |

证据区分已观察、已验证、推测/传闻和未知；新发现不自动成为完整真相。重要征兆同时提供文字，不只靠颜色、图标或声音。原型用生命与理智双资源；现实精神疾病不作为超能力或失控行为的解释。

| 资源 | 用途 | 恢复/补充 | 设计原则 |
|---|---|---|---|
| 生命 | 身体伤害与普通生存压力 | 休整、医疗卡/物资 | 直观、可预测 |
| 理智 | 异常冲击与禁忌认知的代价 | 有限休整、少量稳定精神事件 | 并非越低越强；耗尽则航程无法继续 |
| 行动点 | 每回合出牌预算 | 每回合重置 | 原型默认 3 点 |
| 工具次数 | 调查与应急手段 | 补给点、特殊奖励 | 明确数量和用途 |
| 线索/档案 | 剧情选择、特定调查路线或装备联动 | 探索获取 | 不把所有线索变成纯货币 |
| 仪式代价 | 某些强效牌的生命、理智或材料消耗 | 由具体牌定义 | 主动付出与遭受伤害分别计算 |

**重要平衡规则：**敌人造成的理智冲击可以被防护类卡牌抵御；玩家主动“支付 4 理智”施放禁忌效果不被普通防护抵销，以免出现无代价的信息循环。

## 调查工具

工具独立于抽牌堆，在遭遇前装备，明确展示可回答的问题、次数和代价。

| 道具 | 获得的信息/效果 | 代价与边界 | 适合打法 |
|---|---|---|---|
| 防风提灯 | 确认一名可视目标本回合的物理动作或持有物 | 每场 1 次；无法解释无形攻击的全部来源 | 新手、稳健 |
| 定向听筒 | 判断声音来自目标本体、场景媒介或其他方向 | 每场 1 次；只能确定声源关系，不能读心 | 机制解谜 |
| 显影粉 | 揭示场景中的接触痕迹、隐藏连接或特定符号 | 一次性消耗；并非全部异常都可显影 | 场景调查 |
| 听潮贝壳 | 回答一个限定问题，例如“主要伤害肉体还是理智？” | 每场 1 次，主动支付 3 理智；可能留下后续事件标记 | 高风险禁忌流 |

“回视”属于后续提案：超自然窥探若有额外损失，必须在使用前提示触发条件和总费用。显影粉的库存/消耗与声源证据链详见机制文档，不以草案代替已实现能力。

## 卡牌与构筑

武装、防护、调查、干预、禁忌五类用于内容组织。玩家可混合调查针对、稳健应急与禁忌交换三种倾向，不设调查流唯一正确路线。

## 世界观与海域

调查船收到废弃航路上的求救信号：坐标不存在于官方海图，不同船员记得不同内容。失踪船只、矛盾灯船日志与逐渐失真的航道记录引导调查。玩家先面对残迹、代理人、仪式和受影响的人，不急于归因于某位古神。
以下保留原始三个海域的世界观定位；旧称“灰雾群岛”统一改为“灰雾航道”。完整五海域的新增区域、递进与 Boss 分配由[内容扩展设计](CONTENT_EXPANSION_DESIGN.md)维护。


| 海域 | 主调 | 事件与敌人 | 核心新机制 |
|---|---|---|---|
| 灰雾航道 | 人类世界出现不合理细节 | 失踪船员、伪装者、走私船、封闭灯船 | 征兆读取、普通调查、双候选意图 |
| 尸骸之海 | 人与海中之物界限模糊 | 异化船员、漂流祷告者、错误的海洋标本 | 媒介、传闻与验证、理智代价 |
| 无星深渊 | 经验和记录不再保证完整解释 | 重复出现的船舱、无形仪式、无法确认本体的海上存在 | 封印/撤离目标、复杂但可预告的响应规则 |

击退处理实体，阻断处理仪式或媒介，封印限制联系，撤离只需撑到救援或取证完成。胜利不意味着已经解释或征服异常本质。

### 首轮叙事样例

- **第十三名船员**：十二人船上出现十三份使用过的餐具。可查日志、隔离或留下观察；不直接揭晓身份，代价与分支细化见机制文档 Part 07。
- **漂灯下的回声**：空潜水服位于灯船下层舱室，三只铜铃装于舱壁，隔舱门后传来回声。常驻任务行动《绘制封线》每回合一次、1 行动，在甲板／舱门四处缺口完成 4/4 封线即胜利；调查媒介提供更优路线但不是必需。节拍、媒介状态和三回合路线见机制文档 Part 04。

## 海图与长期成长

节点包括普通敌人遭遇、调查事件、补给、船载档案舱／海上打捞点和区域 Boss 战。节点呈现可信范围内的线索，不能全部成为无差别问号。船只通过短过场、声音与环境变化连接节点，玩家不登陆打捞目标。

航图采用开局一次生成的分层分叉／合并有向图，以一个主种子派生独立的拓扑、内容、遭遇与可见性随机域。玩家每次只选择已获知的相邻航路；旧海图可补齐当前隐藏出口，望远镜可侦察所选航向的下一段，不重抽地图。普通可分支节点按 40% 单出口、42% 双出口、18% 三出口采样；起点、终点前一层和终点按航程结构处理。仅连接邻层、避免大跨度；每段移动由三维航行短动画承接，减少动效可关闭位移与摇晃。实现边界与存档规则见 [航海选路](FRAMEWORK.md#航海选路局外)。


跨局优先解锁卡池、初始工具、已验证档案和叙事分支，避免大量永久数值加成。变体敌人应以征兆说明与旧规律的差别；不随意换答案。档案、航程库存及跨局系统均是后续范围。

## 视觉与交互方向

海洋哥特、潮湿旧木、铜器、盐蚀、航海日志、海雾和过时无线电；固定战斗镜头配清晰牌区。异常通过局部照明、物件变化和音画错位表达，避免触手、霓虹与血浆堆砌。任何扰动都不得破坏费用可读性和操作准确性，关键声音有文字替代。

详细色样、构图、动画与材质要求只在机制文档维护；模型生成、低模、Unity 和归档见 [模型全流程](MODEL_IMPORT_WORKFLOW.md)。Unity 架构、数据接口与存档契约见框架指南。

## MVP 与验收

核心问题：**调查得到的信息，是否真正改变后续策略出牌？**

| 内容 | 首版范围 |
|---|---|
| 角色 | 1 名调查员；无船只操控 |
| 地图 | 一条航线经过 6 个地点；全图预生成后仅局部可见，自动节点航行 |
| 战斗 | 3 点行动、每回合抽 5 牌、抽弃牌循环 |
| 卡池 | 约 18 种卡牌（并非要求每局都出现） |
| 道具 | 4 种，初始可装备 2 件 |
| 敌人 | 2 种普通敌人 |
| Boss | 1 场隔舱门封印任务式 Boss 战 |
| 事件 | 2 个可分支调查事件 |
| 美术 | 1 个完整 3D 战斗场景，优先灰盒验证 |
| 时长 | 约 10–15 分钟/局 |

开发顺序：卡牌循环 → 公开/双候选征兆 → 提灯/听筒 → 双资源与主动支付 → 非击杀目标战 → 短航程与奖励 → 正式氛围表现。机制灰盒验证期间，同步制作一个灯船下层舱室视觉样板，再扩充内容。

试玩验收：玩家能解释已知/未知；调查确实改变计划；无调查也有替代解；失败可从日志理解；奖励/工具促成不同打法；完整短航程不被重复查询拖慢。性能、美术及具体场景检查见机制文档的验收章节。

## 待验证决策与风险

| 问题 | 首轮选择与验证方向 |
| --- | --- |
| 隐藏哪类信息 | 先隐藏行动类别，不同时隐藏类别、数值和媒介；避免纯猜拳 |
| 工具按场还是航程扣次 | 常规工具先每场一次；航程消耗品另测，避免固定调查税 |
| 理智耗尽 | 采用[理智与船员设计的当前决定](SANITY_AND_CREW_DESIGN.md#6-理智-0停止调查不用保险修补失败)：理智 0 立即结束本次航程，不设复活保险；仅可在归零前按场景公开目标主动撤离 |
| 档案保留多少 | 优先已验证规律与叙事，不直接公开所有新敌人行动 |
| 多调查员与复杂养成 | 首版不做，核心玩法成立后再扩展 |
| 目标战拖沓 | 出牌应影响承伤和推进速度，不只是重复点任务按钮 |
| 信息/UI 膨胀 | 一次调查回答有限问题，证据可回看，不把卡牌变成数据库操作 |

## 对外短述

《未测之海》是一款克苏鲁调查题材的回合制卡牌 Roguelike。乘调查船深入无法被完整描绘的海域，用卡组、工具和残缺证据面对异常。你可以窥探真相，也可以在未知中求生；目标是带着足够的证据活着回来。

**宣传语：**有些深渊，本就不该被探知。*Some depths were never meant to be known.*

名称与世界设定为原创草案；正式发行前需做名称重名及商标检索。
