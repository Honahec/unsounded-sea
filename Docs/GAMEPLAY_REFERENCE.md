## 1. 共用规则与术语

### 1.1 资源与回合

| 元素 | 当前作用与限制 |
| --- | --- |
| 生命 | 标准航程初始／上限 60；承受生命伤害，归零立即失败。治疗不超过上限。主动支付生命的牌要求支付后至少剩 1。 |
| 理智 | 初始／上限 30；承受异常冲击，也可作为禁忌效果的主动费用。归零立即失败；主动支付必须至少剩 1，不能被理智防护抵销。 |
| 行动 | 每回合重置为 3；用于出牌、船员支援及部分场景操作。零行动不妨碍使用合法的零费效果。返还行动仍要求先付得起原费用。 |
| 格挡 | 抵扣生命伤害，按抵扣量消耗；不能抵扣理智冲击或主动生命支付。下一回合开始清零。 |
| 理智防护 | 抵扣被动理智冲击，按抵扣量消耗；不是恢复理智，也不抵扣主动理智支付。下一回合开始清零。 |
| 补给 | 航程共享资源，初始 3、上限 8；用于购买、招聘、治疗与筹备等。达到上限不会继续累积。 |
| 抽牌堆／弃牌堆 | 战斗开局洗牌，每回合抽 5；抽牌堆空时才将弃牌洗回。打出的牌先离手，效果完成后才进弃牌／消耗区，因此不能在自己的抽牌效果中抽回自己。 |
| 消耗 | 打出后进入本场消耗区，不再洗回；不是永久删除已学卡牌。物资则扣库存，二者不同。 |
| 保留 | 指定的卡牌实例跨过一次回合结束而不弃掉；不是复制，也不减少下回合基础抽 5。已打出的牌不会凭旧保留标记再次保留。 |
| 常驻遭遇牌 | 由关卡直接给予，始终留手，不占 12 张普通行动牌，不进入抽弃牌循环；只在对应遭遇使用。 |

敌方先锁定本回合行动，再轮到玩家；调查只改变已知信息，不重新随机。结束回合后，普通未保留手牌弃置，再结算敌方行动。任一次结算使生命或理智归零，立即停止后续结算，不能用之后的治疗救回。

### 1.2 情报、目标与联动

| 术语 | 精确含义 |
| --- | --- |
| 征兆 | 可见动作、声响等现象；看见征兆不等于确认真实意图。 |
| 意图已确认 | 当前回合的真实行动已公开或查明。只有一个候选的敌人自动满足；公开节奏行动也满足，不要求先花费调查。下回合重新判断。 |
| 可观察动作 | 可用提灯式调查确认的动作；不可观察目标不能强用普通照明，但可由明确允许的禁忌牌处理。 |
| 声源／伤害类别 | 声源回答“声音来自哪里”；伤害类别回答“威胁涉及生命、理智或召唤哪些类别”。它们本身不等于确认完整意图。 |
| 新答案 | 本回合此前未获得的该对象、该问题的答案。卡牌联动中的“调查牌新答案”只计调查牌实际取得的信息，不把工具／船员查询混入。 |
| 调查接力 | C039、C041、C050 共用每回合最多一次返还 1 行动；不能三张各返一次。C092 另要求同一目标两种不同问题的新答案。 |
| 已观察／已验证 | 已观察是取得现象或公开来源；已验证是完成允许的证据核验。公开召唤来源不直接满足“来源已验证”。 |
| 媒介／场景连接 | 可供调查与验证的联系；只有已验证且允许破坏的媒介才能被 C056 破坏。不是任意装饰物都能互动。 |
| 可打断／可封缚 | 由目标当前规则明确授予的权限；打断牌不能取消任意行动，封缚只取消本回合允许封缚的攻击，不等于击退。 |
| 召唤物 | 由 Boss 规则标记的单位；相关额外伤害、封缚和验证以该标记为准，不按外形猜测。 |
| 场景行动 | 成功执行的任务／机关操作，可触发格挡、抽牌和折扣联动；一般攻击或纯调查不自动算作场景行动。具体次数受关卡限制。 |
| 普通任务 | 非 Boss 阶段锁的封线／撤离等任务。写明“普通任务”的牌不能越过 Boss 机关、阶段或最终目标。 |
| 后备效果 | 卡牌只在规定的无对应机制／无合法目标情形提供抽牌或防护；对应机制存在但次数用完、证据不足时，不保证能改拿后备收益。 |
| 目标选择 | 可能是敌人、另一张牌、证据组合或机关，不全是敌方。多目标操作确认完整目标前不扣费。 |

### 1.3 航程状态

| 状态／标记 | 作用与持续范围 |
| --- | --- |
| 被注视 | 0–3 层，C074 和部分事件增加；换幕减 1。达到 3 时，事件先提供遮蔽或保留踪迹的选择；不是自动扣血或强制乱出牌。 |
| 已测航标 | 经航程调查获得，带入下一场；C096 可消耗它换额外抽牌与理智防护，战后无论是否使用都清除。 |
| 受伤船员 | 暂停该船员战斗支援与航程能力；补给节点可治疗。不是调查员的生命伤害。 |
| 信任 | 满足船员对应海域的 Boss 胜利条件后获得，开放相应安全点服务；不是直接伤害加成。 |
| 接驳凭证 | 事件取得，下次成功招聘少付 1 补给，用后消失，幕末过期。 |
| 蓄势 | 仅非灰雾普通战：第 4 回合正伤害 +2，第 5 回合 +3，此后每回合再 +1。零伤害不被抬成伤害；UI 同时更新公开威胁。 |
| 低理智阈值 | 12／5 是当前提示阈值；不能据此推导存在随机失控、费用变动或自动强制出牌。实际可用性仍检查具体费用与效果。 |

### 2.7 守卫—锚点牌的现状边界

M05 不再要求“绑定航标→撤离”才能获胜，但仍保留**可选的守卫—锚点联动**。守卫召唤入场且尚未牵引时，C042 可查连接，C052／C082／铭牌拓印器／显影粉可验证公开对应，C066 可牵引已验证的守卫，进而触发 C010 的额外伤害与绳钩腰带返还。牵引本身不击退、不压制守卫，也不推进胜利计数；仍须击退全部五名守卫。场上没有可用守卫时，C042／C052 不改拿抽牌，C066 可拿 5 格挡，C082 不可用；非 M05 且无该机制时，C052 改为抽 1。

## 3. 物品与装备

### 共通规则

- 物品共 25 种，稳定 ID 见下表。类型分为调查工具、航行工具、消耗品、装备。
- 战斗调查工具最多装入 **2 件**，每件每场 **1 次**；`i09` 显影粉虽是消耗品，但每带 1 份也占 1 个调查工具位。初始已掌握并装入 `lantern`、`listener`。
- 战斗消耗品最多带 **2 份**（可以同名）；物资箱最多存 **6 份**，同一种最多 **2 份**。`i12` 不能带入战斗。用掉的消耗品在战后从库存扣除；未用掉的保留。
- 装备最多装 **3 件**，必须各不相同；带“引擎”标记的装备最多 1 件。初始拥有并装备 `i17`。第一幕初始整备可在 `i17`、`i18`、`i19` 中三选一起步装备，该选择每航程一次并替换默认 `i17`。
- 工具与装备不能重复取得。补给船购买消耗品每份 **1 补给**，工具或装备 **2 补给**；每个补给节点只能完成一次商店购买。商店按当前海域／幕末威胁生成库存，通常每类型取至多 2 项，最后整备可追加幕末推荐物资。独立奖励或幕末奖励可提供 1 件尚未拥有的装备。
- “理智防护”只抵挡被动理智伤害，不能抵销主动支付的理智。所有战斗物品仅能在玩家回合、次数/行动/合法目标均满足时使用。

## 5. 档案与仪式

### 档案

- 档案不是独立牌堆，也不会自动把本场当前证据变成跨战斗知识。战斗胜利后，只归档 `Verified`（已核实）、规则为 `source-v1` 或 `anchor-v1`、且具有非空主体类型和事实的稳定证据；同一稳定键的新记录覆盖旧记录。失败不归档。
- 当前调查问题种类为：可见动作、声源、伤害类别、盐格、锚点、继电器、连接。能跨战斗保存的实际稳定规则只有两类：**来源记录**（`source-v1`）与**锚点对应**（`anchor-v1`）；其余观察通常只在当场或本回合有效。
- 来源档案会影响内容解锁：`c091` 奖励/受信任船员学习要求至少 1 条来源记录；封存标本在档案节点交付为“来源索引”也要求已有来源记录，并可补入 `c040`「对照旧档」。档案员可在档案节点学习 `c048`「复核证据」。具体卡牌效果见卡牌章节，不在此重复。
- “核验航标”不是永久档案：它放弃档案节点其他收益、揭示全部后续路线，并添加“已测航标”标记；标记传入下一场战斗，战后移除。
- 封存标本花 1 补给在事件取得，保存到交付或航程结束；档案节点可消耗它换 1 补给、整理来源索引，或只记录已学行动的处置建议。后两者均不会直接改当前牌组（来源索引只在尚未学会时补入 `c040`）。

### 仪式

当前仅定义 **1 个仪式**：`ritual:echo`「遮断回声」。完整生命周期如下：

1. **学习**：抵达尚未解决的档案或事件航点、且尚未掌握时，可选择“抄录仪式”。这会放弃该航点其他收益并解决航点；无补给费用。
2. **准备**：已掌握且当前未准备时，只能在可编辑行动簿的安全整备时机（初始整备或补给节点）准备；不消耗补给。重复准备不可叠加，始终只有下一场 1 次。
3. **带入**：准备状态写入下一场战斗载荷，不占调查工具、消耗品或装备槽。
4. **使用**：玩家回合选择一只当前正在攻击、可由召唤物目标规则列出且尚未被压制的召唤物；必须剩余理智 **大于 3**。支付 **3 理智**，取消该目标本回合攻击并耗尽仪式。非法目标不扣理智；主动支付不能被理智防护抵销，但可触发 `i23` 铅衬笔记匣。
5. **过期**：该场遭遇结束时，无论胜败、是否使用，准备状态都清除；若曾准备则状态显示为“上次筹备已失效，可再次筹备”。仪式知识在本次航程内保留，可在以后安全整备点再次准备；不表示跨新航程永久解锁。

- 每回合最多一次封匣尝试；正确则永久关闭，错误承受4理智冲击并消耗该次尝试。
- 关闭第三匣立即解除护持，并取消本轮尚未发生的新召唤；已存在的召唤物不消失。
- 阶段变化不重新抽取当回合已经提交的攻击。第二阶段9生命攻击从后续 `BeginPlayerTurn` 提交。
- 骨片侍从 `b02-bone-servant`：10生命，每轮3生命伤害。
- 潮囊信使 `b02-tide-messenger`：12生命，每轮为发声囊恢复6生命，不超过42；恢复行动可普通打断。
- 第一阶段召唤回合优先规则：全局回合>6且信使不在场时召唤信使，否则尝试召唤侍从；已有对应槽位存活时不会生成重复敌人。召唤本身可打断。
- 新召唤物不在召唤当轮出手；已有召唤物继续行动。击破发声囊即可胜利，无须另清所有召唤物。

#### 盐格司衡 `m03`

- 开局有7个已开启安全格；四枚封栓目标公开标示，未开的危险位置不公开。
- 开启安全格显示相邻八格危险数；测读只显示邻近危险数，不打开、不直接证明该格安全。
- 开到危险格承受基础6生命伤害及2理智冲击，该危险格随后停用；生命部分经过场景失败伤害修正，仍经过正常防护结算。
- 雾灯蛾群 I／II：各6生命，各每轮2理智；最多两个槽位。偶数回合填入首个空槽，已击退的槽位可以再次召唤；新入场当轮不攻击。
- 本体和蛾群上述常规行动不可普通打断；专门的召唤取消／召唤物压制规则另算。
- 激活第四封栓立即胜利，不要求清理蛾群。不要在面向玩家的图鉴直接列出内部雷区坐标或种子变换答案。

#### 无灯旗舰 `m04`

1. 初始两座继电器均断电；阶段1要求 **R1正接、R2反接**。每回合只能调校一次，满足后在下一玩家回合进入阶段2。
2. 阶段2按公开条件开锁，每回合最多一次正常释放：
   - I隔离锁：R1断电、R2反接。
   - II导压锁：I已开，R1正接、R2反接。
   - III泄压锁：II已开，R1正接、R2断电。
3. 警报初值5，每个阶段2敌方结算结束减1；归零额外造成12生命伤害，再重置为3。特定牌可延缓或压制警报。
4. 第三锁完成立即解除护持，取消本轮本体攻击和后续阶段2警报；不会自动清除场上执旗兵。
5. 全局第2回合敌方阶段安排召唤空甲执旗兵 `b04-flag-soldier`：14生命，后续每轮4生命伤害。专门的取消召唤效果可以取消这次预定入场。
6. 本体和执旗兵的常规攻击不可普通打断。

## 7. 航海节点与事件

### 7.1 三幕与五海域

一局航程共三幕，每幕实际访问 11 个节点，共 33 个；地图上未走的分支不算额外必经节点。全程发生在海上，不含可游玩的陆地。

| 海域 ID | 名称 | 航程位置 | 主要规则内容 |
| --- | --- | --- | --- |
| `fog` | 灰雾航道 | 第一幕固定 | 基础征兆与防护；Boss 从雾海来客、黑潮压舱者、空心航标中抽取。 |
| `bones` | 尸骸之海 | 第二幕三选一 | 普通敌人来源调查与节奏／隐匿战；第 4 种遭遇可等待撤离 3 轮，也可用牌提前推进。 |
| `inverted` | 倒悬潮庭 | 第二幕三选一 | 普通敌人调查与节奏／隐匿战；第 4 种遭遇可封线 3。 |
| `fleet` | 无灯裂海 | 第二幕三选一 | 普通敌人调查与节奏／隐匿战；第 4 种遭遇可封线 3。 |
| `abyss` | 无星深渊 | 第三幕固定 | 后段普通敌人；第 4 种遭遇可等待撤离 3 轮或用牌提前推进；终局 Boss 为无星守望者或沉钟之母。 |

第二幕 Boss 从 M02／M03／M04 中独立抽取，不与所选第二幕海域绑定。每幕包含四场普通战、一场 Boss、一个事件、一个档案、一个独立奖励和三次整备。第 6 层的险航分支固定双敌，胜利后有两次三选一。

### 7.2 六种节点

| 类型 | 作用与结算 |
| --- | --- |
| 普通战 `Battle` | 进入对应遭遇，获胜继承剩余生命／理智，扣除实际使用物资，展示小结后进入三选一奖励；失败结束航程。 |
| Boss `Boss` | 按本场独立胜利条件结算，不保证能靠攻击本体获胜。前两幕胜利后选择下一海域并领奖，终幕直接结算。 |
| 事件 `Event` | 从当前模板与已满足条件的额外选项中择一结算；不能反复领取互斥收益。 |
| 补给／整备 `Supply` | 可编入 12 张已学的不同卡、调整工具／物资／装备，并使用购买、招聘等独立服务；最后选择一次休整、治疗、安定心神或不消耗补给离开。 |
| 档案 `Archive` | 抄录航路、研读简报、封存记录等互斥选择；船员、标本、航标、仪式可提供额外选项，不等于全部奖励同时取得。 |
| 独立奖励 `Reward` | 四选一；满足条件时可选装备。可只收入行动簿或替换当前牌组一张；放弃获得 1 补给，已满则无额外收益。 |

奖励不提供免费刷新。学习不等于立刻入组：领取卡牌可选择替换，换出牌仍已学；其余整备时再调整。普通战奖励三选一，独立奖励四选一，险航连续两次三选一。
