These recordings were resampled, trimmed, filtered, gain-adjusted and/or layered.

Original work for this project:
Four three-stem scores, modal/additive synthesis, gunshot and giant-body layers,
wind/wake textures, uncanny feedback and outcome cues, authored in Tools/build_audio.py.
No external instrument samples, paid services or artist-style imitation were used.
Original project material is not relicensed as CC0 by this credits file.

Rebuild with Python + numpy/scipy/soundfile and ffmpeg:
  python Tools/build_audio.py
  python Tools/check_audio.py
Runtime audio is imported through Tools/AudioSetup.cs using Unity CLI run_script.
Masters are outside Assets and are not included in the game build.
